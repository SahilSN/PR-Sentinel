# Claude Code — Shared Instructions

@AGENTS.md

The imported `AGENTS.md` contains the rules shared by all coding assistants on this project. Follow it in addition to the instructions below.

- Before feature work, read `PROJECT.md` and follow the milestone and interface specifications relevant to the task.
- Use the current developer's local role instructions, if present, without treating them as team-wide requirements.
- Inspect existing files before editing. Keep changes focused, explain important tradeoffs, and verify behavior with tests when possible.
- If a task conflicts with `PROJECT.md`, flag the conflict instead of silently redesigning the project.

**Personal roles:** Each Claude Code user may create a separate, gitignored `CLAUDE.local.md` in their own clone. Do not commit personal role instructions to this shared file.
